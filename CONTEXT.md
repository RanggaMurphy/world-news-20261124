## The boundary between dossier and briefing

- A dossier statement can be checked against the day's articles.
- A briefing statement explains an instrument, a pattern or a
  place; it is background, and it is written so that it would
  still be true if the day's story had gone the other way.
- Where the two would overlap, the fact lives in the dossier and
  the briefing links to it by reference instead of repeating it.
- If a briefing and a dossier disagree, the dossier wins: it is
  closer to the record.
